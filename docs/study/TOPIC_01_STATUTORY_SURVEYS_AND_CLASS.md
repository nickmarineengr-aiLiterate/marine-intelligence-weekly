## MENTAL SKELETON

Nine branches. Own these and you can construct an answer to most of the 168
mapped questions (69 Oral + 96 Written).

**Revalidated 2026-08-23 against the corrected corpus and left unchanged.**
Every one of the 19 questions the taxonomy tranche moved into D01 lands inside
an existing branch — class notations and Condition of Class in 5, drydock and
corrosion in 8, PSC in 9, the statutory certificate set in 7, flag-vs-RO in 4.
The corpus grew; it exposed no missing concept, so no branch was added. Growth
is not a reason to complicate a skeleton whose whole value is that it is
memorable.

1. **The IMO instrument hierarchy** — Convention → Protocol → Code →
   Resolution → Circular. What binds, what guides, and how you tell them apart.
2. **Entry into force** — the four stages (adoption → acceptance → entry into
   force → implementation), tacit acceptance, and why an amendment's date is
   not its adoption date. *(5 written occurrences — the single most repeated
   family in this domain.)*
3. **Flag State duties** — UNCLOS Art. 94, the III Code, flag State
   performance and self-assessment; India's mechanism.
4. **Recognized Organizations** — the RO Code, what a flag delegates and what
   it cannot, oversight and the limits of RO authority.
5. **Classification** — what class is and is *not*, IACS (UR / UI / PR), class
   rules vs statutory requirements, dual class, transfer, and Condition of
   Class.
6. **The survey regime** — Harmonized System of Survey and Certification;
   initial / annual / intermediate / renewal / periodical; anniversary date,
   windows, ESP, CAP, CMS/CSM; what the CE may credit and what only a surveyor
   may.
7. **The certificate set** — which certificate comes from which instrument,
   who issues it, validity, endorsement, and what makes one invalid.
8. **Hull condition & drydock** — substantial corrosion, diminution limits,
   steel renewal criteria, coating condition, in-water survey, tail shaft.
9. **Port State Control** — clear grounds, more detailed inspection,
   detainable deficiency, detention, appeal, the regional MoUs and the New
   Inspection Regime.

**A-priority means: know this cold.** It is a *compression* set, not a
completeness set. Where two questions test the same concept only the better-
evidenced one is here; its twin sits at B or C so you meet the idea once, well.

**How a question earned A.** Five signals, in this order of weight:

1. **Settled mapping.** Only `VALID_MAPPED` questions may be A. A question
   still in the review queue is studiable but has not been individually
   adjudicated, so it carries no settled priority claim. This is a hard gate,
   not a tiebreak.
2. **Branch anchoring.** Each of the nine skeleton branches gets the question
   that best *builds* it, so the A set reconstructs the skeleton rather than
   sampling the corpus.
3. **Examiner breadth, tier-weighted.** A `confirmed` relationship outranks an
   `inferred` or `header` one. Breadth says a question is real; inside D01 the
   occurrence counts are too flat to rank questions against each other, so it
   is used as a floor, not a score.
4. **Written recurrence support.** A concept that also recurs in the solved
   Written corpus is worth more retrieval practice.
5. **Cross-question leverage.** A question whose answer supplies the frame for
   several others beats a question that stands alone.

**Why this bucket was overwhelmingly a D01 problem is worth knowing.**
`QUESTION_CUES` in `tools/study/study_spine.py` is an ordered, first-match-wins
list and D01 is entry number one, matching `survey|certificat|class`. Inside a
mixed file, *any* question mentioning a survey or a certificate is claimed by
D01 before D04, D05, D07, D09 or D10 is ever consulted — which is how a
container convention, a NOx file and an IOPP checklist all arrived here. The
cue table was **not** edited to fix this: a cue added to shrink a review queue
is a taxonomy change smuggled in as a regex, and the integration contract
forbids it. Two blind spots were recorded instead:

## STUDY METHOD

1. Read the question. **Do not read the answer.**
2. Attempt it cold, aloud, ~60 seconds.
3. Read the 15-second answer. Then the 60-second answer.
4. Study the full MIW answer.
5. Close it. Answer aloud again.
6. Take the examiner follow-up.
7. Delayed recall next session.

Do **not** memorise MIW prose word-for-word. The examiner is testing whether
you can construct the answer, and a recited paragraph collapses on the first
follow-up.
