Concept Map — CO₂ Cylinder Testing Regime (MSC.1/Circ.1318/Rev.1)

Coverage must stay compliant (FSS Code Ch.5 §2.2.1) while cylinders are ashore — stage the testing or arrange replacements. Contents checked in situ by ultrasonic level gauge; >10% short → refill/replace.

Confusable Pairs — Examiner Favourites

⚠ Confusable Pair: Bursting Disc vs Relief Valve
Bursting disc = sacrificial membrane, non-reclosing, instant full-bore, rated at a temperature, replace after use. Relief valve = spring-loaded, recloses, controllable set pressure. Crankcase explosion relief doors are spring-loaded self-closing valves (IACS UR M9) — never call them bursting discs.
⚠ Confusable Pair: Manifold Relief Valve vs Cylinder Safety Disc
The manifold relief valve protects isolatable pipe sections (trapped liquid, passing cylinder valve) — setting per the class-approved drawings. The cylinder safety disc protects each bottle against over-temperature/over-pressure. Both vent through the relief line to open deck.
⚠ Confusable Pair: IGC Code vs IGF Code (vs IP Code)
IGC = ships carrying liquefied gas as cargo (SOLAS VII, Certificate of Fitness). IGF = ships using gas/low-flashpoint fuel (SOLAS II-1 Part G). IP Code = Industrial Personnel, SOLAS Ch. XV — unrelated despite the similar letters.
⚠ Confusable Pair: Type B Tank vs Membrane Tank
Type B (Moss sphere) = independent tank, partial secondary barrier justified by crack-propagation/leak-before-failure analysis. Membrane = non-self-supporting thin barrier relying on the hull, needs a full secondary barrier. Type C pressure vessels need none.
⚠ Confusable Pair: Polar Code 2017 Baseline vs 2026 Amendment
Baseline Code in force 1 Jan 2017 (SOLAS Ch. XIV). The latest amendment is MSC.538(107), in force 1 Jan 2026 — navigation/voyage-planning chapters 9-1 & 11-1 extended to non-SOLAS ships (fishing ≥24 m, yachts ≥300 GT, cargo 300–500 GT), grace to 1 Jan 2027. Answering "2017" to "latest amendment" is the fail.

Topic Clusters — Tap to Recall

Fixed CO₂ System — Protection & Testing
Q1. CO₂ manifold relief valve — setting & line test
Tap to reveal the 15-second answer →
Protects isolatable sections against trapped liquid/passing cylinder valve; setting = design value from class-approved drawings (never a universal number); vents to open deck. Line test: blow-through with dry air/N₂ each survey; hoses ≤10 yr; pipelines pressure-tested at 10 yr.
Q2. Fire in the CO₂ room
Tap to reveal the 15-second answer →
Fight from OUTSIDE: alarm, stop room ventilation, boundary cooling with water; do not enter — heated cylinders self-vent via safety discs, relief outlet on OPEN DECK (cordon it). Afterwards: fixed system unavailable — inform class/flag, interim measures.
Q3. Bursting disc — how does it burst?
Tap to reveal the 15-second answer →
Membrane stress exceeds ultimate strength at rated pressure/temperature → tears along score lines (forward-acting) or snap-buckles onto a knife ring (reverse-acting). Non-reclosing, instant full-bore, temperature-rated, replace after operation. ISO 4126-2.
Q4. CO₂ bottle pressure testing regime
Tap to reveal the 15-second answer →
MSC.1/Circ.1318/Rev.1: 10 yr → ≥10% internal + hydro (fail→50%→100%, rotate sample); before 20 yr and every 10 yr after → 100%. Hoses ≤10 yr; control valves internal exam ≤5 yr; ISO 18119:2018; keep coverage while cylinders ashore.
Survey Readiness & Emergency Systems
Q5. Emergency fire pump fails at Class survey
Tap to reveal the 15-second answer →
Technical → Class → SMS. Be transparent; troubleshoot (prime first, then starting, fuel, line-up); if defective: condition of class/statutory deficiency with time limit; SMS non-conformity, risk-assessed interim measures, DPA/flag informed, re-test with surveyor. FSS Ch.12: ≥40% of required capacity, ≥25 m³/h, fully independent.
Codes & Currency
Q6. Polar Code — latest amendment
Tap to reveal the 15-second answer →
MSC.538(107), in force 1 Jan 2026 (grace 1 Jan 2027): new Ch. 9-1 & 11-1 extend navigation/voyage-planning to non-SOLAS ships (fishing ≥24 m, yachts ≥300 GT, cargo 300–500 GT); plus dual echo-sounders, two non-magnetic heading devices, GNSS-independent fix >80°, enclosed bridge wings (new Cat A/B). CE side: PWOM machinery chapters, Polar Service Temperature.
Q7. What is the IGC Code?
Tap to reveal the 15-second answer →
International Code for the Construction and Equipment of Ships Carrying Liquefied Gases in Bulk — mandatory via SOLAS VII (builds from 1 Jul 1986). Tank types A (full barrier) / B (partial, leak-before-failure) / C (none) + membrane (full). Certificate of Fitness. Current text: MSC.370(93) rewrite (2016); latest: MSC.523(106) hi-Mn steel (1 Jan 2026), MSC.566(109) (1 Jul 2026).
