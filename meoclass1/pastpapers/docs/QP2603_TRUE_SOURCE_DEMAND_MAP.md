# QP2603 — TRUE SOURCE DEMAND MAP

**March 2026, Engineering Management, MEO Class I.**
Written 2026-08-08 at the close of QP2603 production. Companion to
`QP2607_TRUE_SOURCE_DEMAND_MAP.md`, `QP2601_TRUE_SOURCE_DEMAND_MAP.md` and
`QP2602_TRUE_SOURCE_DEMAND_MAP.md`, none of which is modified by this document.

This is the handoff contract to the corpus-production track: what QP2603 actually needed in
order to be verified, how strong the evidence was, and what acquiring a source would unblock.

> **`reference_shelf` is empty on every QP2603 question, by design.** No corpus object was
> fabricated, no object id invented, no PDF page cited. See `MIW_TRUE_SOURCE_CONTRACT.md` §3
> and §5. This map records *demand*, not mappings.

## 1. Classification used

Unchanged from the January and February maps, so all four are directly comparable.

| Code | Meaning |
|---|---|

| **S** | SUPPORTING — cited to establish authority or context; the answer would survive its absence with a narrower claim. |
| **C** | CONTEXT — mentioned for orientation; carries no load-bearing claim. |

| Recommendation | Meaning |
|---|---|

## 4. Corpus temporal model — one NEW state required

February established that corpus objects must be able to represent *current*, *repealed*,
*adopted-not-in-force*, *approved-not-adopted* and *amendment* states. March exercised those and
found **one state the existing contract does not handle**.

> ### NEW REQUIREMENT: a *live external list* is not a document state
>
> Q3 depends on the **Joint War Committee Listed Areas**. This is not an instrument, not an
> edition, and not an amendment state. It is a **continuously revised third-party list** whose
> *current value* is load-bearing operationally but whose *historical values* are what a past-paper
> answer would need — and reproducing either would be wrong within weeks.
>
> The answer therefore deliberately reproduces **no** Listed Areas and **no** premium rates,
> describing only the mechanism. A corpus object for this class of source cannot be a text
> snapshot; it must be a **pointer to a maintained external register**, with an explicit
> "as-at" semantics, or it must not exist at all.
>
> The same shape applies to the **list of Indian ports authorised to issue ship sanitation
> certificates** (already flagged in the January map) and to the **EU Ship Recycling Regulation
> approved-facility list** (Q9). This is now a **3-instance pattern across three papers**, not a
> one-off, and it is handed to the corpus team as a definite architectural requirement.

**Not solved in QP.** No workaround was invented; the answers state the mechanism and say the
current list must be checked.

A second, smaller observation: **ISO 20519 exists in more than one edition and MIW holds none.**
No clause numbers were cited, deliberately, because citing a clause from an unheld edition is
precisely the correct-instrument-wrong-edition failure this series has caught on every paper.
