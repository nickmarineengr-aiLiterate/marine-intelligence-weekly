## 4. Temporal review — **INTAKE FLAG WAS WRONG**

**Intake recorded:** `temporal_review: STABLE / LOW`, no classes, no notes.
**Corrected to:** `CORRECTED / HIGH`, class `guideline edition`.

### The finding

`MSC-FAL.1/Circ.3` exists in three editions and **the number of functional elements changes
between them**:

| Edition | Date | Functional elements |
|---|---|---|
| MSC-FAL.1/Circ.3 | 5 July 2017 | 5 |
| **MSC-FAL.1/Circ.3/Rev.2** | **7 June 2022** | **5 — operative at this sitting** |
| MSC-FAL.1/Circ.3/Rev.3 | 4 April 2025 | **6** — `Govern` added ahead of `Identify` |

Rev.3 post-dates the March 2024 sitting by **thirteen months**. An answer written from
currently-available material would state six elements and would be **wrong for this paper**.

### Why this matters beyond one question

The **only built MIW object that touches this topic is `QP2606-Q5`** (June 2026, the ISM Code
and the evolution of the SMS), whose route step 6 states the elements as **six**, correctly for
June 2026. Had the reuse search been run lexically and the step imported, a functional element
that did not exist would have entered a March 2024 answer.

> **This is the QP2508-Q3 failure mode exactly, and it is now 2 for 2.** An intake flag of
> `STABLE / LOW` on a question whose governing instrument was re-issued between the sitting and
> the present day. **The flag is not evidence. Only the sweep is.**

### Second temporal check — class requirements

**IACS UR E26 and UR E27 were NOT in application at this sitting.** The original 1 January 2024
application was withdrawn; the revised requirements apply to ships **contracted for construction
on or after 1 July 2024** — four months after this paper. Recorded in the study guide, not
asserted in the model answer.

### Third temporal check — the ISM linkage

`MSC.428(98)` (16 June 2017) requires cyber risk to be addressed in the SMS no later than the
first annual verification of the company's DOC **after 1 January 2021**. That date is comfortably
**before** the sitting, so the obligation was live in March 2024. No regression required.
