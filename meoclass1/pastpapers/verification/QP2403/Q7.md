## 3. The trap this question is built on, resolved from the text

The printed words are *"Which all IMO instruments covered in the code"*. There are **two correct
answers and they are different**, and the previous session flagged this before any drafting began.

| | What it is | Where |
|---|---|---|
| **Six subject areas** | The Code's own **scope**. It does not name a single convention. | A.1070(28) ¶6.1–6.6 |
| **The treaty instruments** | The conventions amended to make **use of the Code mandatory**, and therefore the audit scope. | A.1187(33) preamble + Annex 1 |

**Paragraph 6 verbatim, the six:** safety of life at sea; prevention of pollution from ships;
standards of training, certification and watchkeeping for seafarers; load lines; tonnage
measurement of ships; and regulations for preventing collisions at sea.

**Maritime security is NOT among them.** This was checked directly rather than inferred: the
resolution's preamble does use the phrase *"maritime safety, security and protection of the marine
environment"*, but the operative scope at ¶6 does not extend to security instruments. An answer
listing seven areas including security is wrong against the text.

**The mandatory-application chain**, recited in the A.1187(33) preamble and confirmed against the
A.1070(28) preamble:

| Instrument | Made III Code mandatory by |
|---|---|
| Load Lines 1966 | A.1083(28) |
| Tonnage 1969 | A.1084(28) |
| COLREG 1972 | A.1085(28) |
| SOLAS 1974 | MSC.366(93) |
| STCW 1978 | MSC.373(93) |
| STCW Code | MSC.374(93) |
| LL Protocol 1988 | MSC.375(93) |
| MARPOL | MEPC.246(66) |
| MARPOL Protocol 1997 | MEPC.247(66) |

This chain is also the answer to the follow-up *"the Code says 'should' everywhere — how is it
mandatory?"* The Code was never redrafted into obligation language; the **conventions** were
amended to require its use.

## 5. Temporal review — **CONFIRMED STABLE, checked not assumed**

The intake recorded `STABLE / LOW`. Per the standing rule the flag was treated as *unevaluated*
and re-checked. On this question the intake happens to be right, and the reason is recorded rather
than assumed.

- **A.1070(28) is unamended** between adoption on 4 December 2013 and the March 2024 sitting. It
  is the Code at this sitting and at the October 2025 sitting. Operative ¶2 permits amendment on
  the recommendation of MSC and MEPC; none had taken effect.
- **The companion instrument DID move, and inside the window that matters.** A.1187(33), adopted
  **6 December 2023**, replaced the 2021 list **A.1157(32)** — **three months before this sitting**.
  The answer cites the 2023 list. Any material citing the 2021 list is superseded at this sitting.
  This is why the intake flag being "right" is not the same as the intake flag being *evidence*.
- **A.1054(27) is revoked**, so citing the 2011 Code as current is citing a revoked instrument.
- **No claim in the answer turns on a date falling inside March 2024.** The PDF-metadata bound
  established in the plan (host generated the source file 1 April 2024) is therefore sufficient.

**Nothing later than the sitting appears in the Model Answer.**

## 6. Limitations accepted

1. **Instrument count.** Neither A.1070(28) nor A.1187(33) states how many instruments the audit
   scope contains. The figure of **nine** is a widely used summary — SOLAS 1974, SOLAS PROT 1988,
   MARPOL, MARPOL PROT 1997, STCW 1978, LL 1966, LL PROT 1988, TONNAGE 1969, COLREG 1972 — but
   A.1187(33) Annex 1 additionally carries a **SOLAS PROT 1978** column, which is why a count of
   ten also circulates. **The Model Answer lists the instruments and does not lead with a count**;
   the Study Guide states the nine explicitly as a summary and says so. `C_ACCEPTED_LIMITATION`.
2. **IMSAS procedure.** The Framework and Procedures for the Member State Audit Scheme
   (A.1067(28), later A.1156(32)) was **not** re-read this session. The answer says the Code is the
   standard a Member State is audited against — which follows from the mandatory-application chain
   in both resolutions read — and makes **no claim about audit periodicity or procedure**.
   `C_ACCEPTED_LIMITATION`.
3. The Code's own cross-reference at ¶60 is to "the relevant resolution adopted by the
   Organization" for port State control procedures. Which edition of the PSC Procedures was current
   at this sitting was not established; nothing in the answer turns on it, and the reference is
   reproduced as the Code's own. Same posture as `Q6.md` §7 item 2.
