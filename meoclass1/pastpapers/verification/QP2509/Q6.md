## 2. The donor-readiness defect - host recurrence hints are DIRECTIONAL

This is the reportable finding of the question.

**What the two objects record about each other:**

| Object | `host_recurrence_hint` |
|---|---|
| `QP2601-Q2` (January 2026) | `... 2020/MAR/Q5, 2022/JAN/Q5, `**`2025/SEP/Q6`**`, 2026/JAN/Q2` |
| **`QP2509-Q6`** (September 2025) | `... 2020/MAR/Q5, 2022/JAN/Q5, `**`2025/SEP/Q6`** |

**The donor names this sitting. This sitting cannot name the donor** - the September 2025 source
paper was printed before the January 2026 sitting existed, so its printed recurrence annotation
stops short.

If recurrence edges are constructed from **each paper's own hint list without symmetrising**, then
an **earlier** paper can never see a **later** paper that names it. Every such pair is invisible in
one direction, and the direction that is lost is exactly the one a solving session needs when it
works backwards through the years - which is what this whole 2024-2026 programme is doing.

**Consequences observed here:**

- `QP2509-Q6` was scored **Tier C, no donor, fresh research**, when a near-identical built answer
  existed.
- Had the intake been trusted, this question would have been researched and authored from scratch,
  duplicating an existing verified object and risking divergence between two answers to the same
  printed question.

**Recommendation carried to the report:** the donor-readiness derivation should treat host
recurrence hints as an **undirected** relation - if paper A's hint list names sitting B, the edge
B-A exists as well as A-B. This is a change to `recurrence_model.py` / `build_reuse_map.py` and is
**not** made in this session, because it would alter the reuse map for the whole corpus while a
paper is mid-production. It is recorded as the next derivation fix.

> **This is the second donor-readiness finding on this paper.** Q8 established that the model works
> at **question** granularity and is blind to a **limb-level** exact donor. Q6 establishes that it
> is blind to **backwards** recurrence edges. Neither is a data error; both are derivation
> characteristics worth knowing before ranking the next paper.
