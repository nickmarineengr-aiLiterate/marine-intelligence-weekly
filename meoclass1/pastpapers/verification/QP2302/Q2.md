**Technical ambiguities identified before drafting:**

- Whether 'Which all IMO instruments covered in the code' asks for a list of conventions or for the subject areas the Code addresses. It asks for the instruments - the Indian-English elision is of 'are', so the demand is 'which IMO instruments are covered'. Both are given, because the subject areas at annex paragraph 6 are the natural way to organise the instrument list, but the instruments are named.
- Whether the KPIs in limb b) are the Code's own evaluation criteria or general management indicators. They are the Code's own, at annex paragraphs 42 to 44, and answering with invented management metrics answers nothing.
- Whether coastal State responsibilities under the Code mean UNCLOS jurisdictional rights. They do not. The Code addresses what a coastal State should PROVIDE and DO - navigational services, hydrographic and meteorological information, casualty response - not the extent of its maritime zones. - Whether the Code binds a State in respect of instruments it has not ratified. It does not, and the Code says so expressly at annex paragraph 2. This is a scoring point that most candidates miss.
- Whether to describe the Code as mandatory. It is - through the amendments that brought the III Code and the audit scheme into the mandatory instruments - and saying how it became mandatory is worth a mark. The date and mechanism are stated at the level the held sources support.
