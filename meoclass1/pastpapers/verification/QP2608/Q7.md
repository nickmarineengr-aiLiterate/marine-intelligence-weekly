electrical engineer regarding safe entry and cleaning procedures inside the dead main switchboard.

main switchboard fully operational. [5]

## 2. Statement-type separation

- **Convention / Code:** ISM Code elements 6, 7, 8, 10, 12; SOLAS ch. II-1 at concept level; STCW at
  competence level.
- **Class rule:** the HV threshold, earthing facilities and interlocks on HV switchgear.
- **Flag State guidance:** the code of safe working practice on electrical work and proving dead.
- **Company document:** the permit form, its validity, its signatures — the ship's SMS is made
  controlling.
- **Installation document:** the approved relay setting schedule and the maker's manual.
- **Engineering practice:** the isolation sequence, stored energy, the closing order and the
  restoration sequence.
