## 2. Statement-type separation

- **Mandatory instrument:** RO Code Parts 1 and 2, via SOLAS / MARPOL Annexes I and II / 1988 LL
  Protocol amendments.
- **IMO guidance:** RO Code Part 3.
- **Association instruments:** IACS UR, UI and PR — binding on Members by association rule, reaching
  ships only through class rules or through convention interpretation.
- **Reasoning from primary text:** claim 3.7, labelled.

## 3. Dropped / not asserted

| Item | Why |
|---|---|
| A number of IACS Members | Membership has changed over time; no current figure verified. A stale count is a needless error. |
| "Classification society = Recognized Organization" | False as a general equation — a society is an RO only to the extent a flag delegates, and scopes differ by flag. |
| "The RO Code is mandatory in its entirety" | Only Parts 1 and 2 are; Part 3 is guidelines. |
| Any claim that the Administration transfers responsibility to the RO | It delegates function; responsibility is retained. |
