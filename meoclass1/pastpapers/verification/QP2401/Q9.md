## 1. What the question demands

> Referring to the IMO Instruments Implementation Code. a) Briefly Discuss the objectives of the code and strategy recommended to flag state to achieve the objective. Which all IMO instruments covered in the code. (6) b) What are the key performance indicators for evaluation of Flag state performance as per the code. (4) c) Briefly discuss the Flag state, coastal state, and Port state responsibilities. (6)

**Intent.** Three limbs against one named Code. Limb (a) is really three tasks - objective, strategy, instruments - inside six marks. Limb (b) is precise recall of one section of the Code for four marks. Limb (c) asks for all three State roles in six marks, which the Code makes tractable because Parts 2, 3 and 4 share a structure. The examiner is testing whether the candidate has opened A.1070(28).

**Mark allocation.** 16 printed as 6 + 4 + 6, identical to the March 2024 sitting of the same question. Note for the QP2510 family that the same words are printed there as 6 + 5 + 5, so the answer is re-weightable but not re-writable. Limb (a) must be split three ways; limb (b) is fast and precise; limb (c) is six marks for three States, so two each.

**Examiner expectation.** That the candidate has read A.1070(28). The tell-tales are the paragraph 3 strategy in its three parts, the six subject areas at paragraph 6, the CTL exclusion at paragraph 43, the eight coastal services at 48 and the three port obligations at 56. General UNCLOS flag-State material scores poorly because it is not what was asked. At this sitting there is an additional expectation of currency: A.1187(33) is one month old.

The answer is decomposed into these required components:

- Which instrument the question names, its resolution number, and what made a recommendatory text mandatory
- (a) The objective of the Code in its own words, and the qualification that follows it
- (a) The strategy the Code recommends a State adopt
- (a) Which IMO instruments the Code covers - and why there are two correct answers
- (b) The key performance indicators for flag State evaluation, and their stated purpose
- (c) Flag State responsibilities under Part 2
- (c) Coastal State responsibilities under Part 3 and port State responsibilities under Part 4
